# Agilancers — hero character

The main character for a 3rd-person action/platformer: a man with an
undercut and man-bun, black triangle tee, dark jeans, dark running shoes and
an open white lab coat with the sleeves rolled to the elbows. He carries a
lance in his right hand and a shield strapped to his left forearm.

The body of the lab coat (chest panels, sides, back and the long tail with
its vent) is **not animated**. Only the shoulder yoke, collar and sleeves are
skinned; everything below the yoke seam hangs off the shoulders and armholes
and is driven by a cloth solver running in **WebGPU compute (three.js TSL)**,
with a CPU fallback for the WebGL2 backend.

## Run the viewer

```bash
npm install          # only needed for the local three.js copy used by the test harness
npm run serve        # http://localhost:8080
```

The viewer (`index.html`) lists all 42 animations of the Universal Animation
Library 2 (grouped; the lance/shield combat set first), has playback speed,
root-motion toggle (character actually travels, coat trails behind), wind,
cloth stiffness, collider display, and the 10 lance and 10 shield designs.

## Assets

| File | What |
|---|---|
| `assets/models/agilancer_hero.glb` | Skinned hero (65-bone UAL2 rig), 43 animations, baked textures. Mesh `CoatCloth` is the simulated coat body (see below). |
| `assets/models/agilancer_arms.glb` | `Lance_<design>` / `Shield_<design>` nodes for the 10 designs, authored in the hero's bind pose. |
| `assets/models/UAL2_Standard_RM.glb` | Original library with root motion (clips only are used). |
| `assets/source/*.png` | The supplied texture sheets (outfit, lances, shields). |

### Using the coat cloth in the game

`CoatCloth` is a regular skinned mesh (so it still works without physics),
whose vertices form a `rows × cols` grid; the grid coordinate of each vertex
is in UV set 1 and `userData.cloth` (glTF extras) holds
`{rows, cols, ventCol, ventRow}`. `src/cloth/CoatCloth.js` turns it into a
simulated mesh:

```js
import { CoatCloth } from './src/cloth/CoatCloth.js';
const cloth = new CoatCloth({ renderer, clothMesh, useGPU: renderer.backend.isWebGPUBackend });
scene.add(cloth.mesh); clothMesh.visible = false; cloth.reset();
// every frame, after mixer.update() and hero.updateMatrixWorld():
cloth.update(dt);
```

* Row 0 is sewn to the yoke (follows shoulders, shoulder blades and the upper
  arms at the armholes); rows 1–3 are softly held so the drape leaves the
  shoulders smoothly. Everything else is free.
* Solver: Verlet integration at 120 Hz, Jacobi distance constraints
  (structural / shear / bend), column tethers against stretching,
  capsule colliders on torso, hips, legs and arms, air drag + wind.
* `src/cloth/ClothGPU.js` (TSL compute) and `src/cloth/ClothCPU.js`
  implement the same algorithm; `dev/clothtest.html` checks they agree.

## Rebuilding the assets

The hero is generated by script in Blender (bpy) from the UAL2 mannequin's
skeleton, skin weights and body volume plus the supplied texture sheets:

```bash
uv venv -p 3.13 .venv-bpy && uv pip install --python .venv-bpy/bin/python bpy==5.2.3 numpy scipy scikit-image pillow
PY=.venv-bpy/bin/python
$PY tools/build/textures.py                 # slice the texture sheets -> build/pieces
$PY tools/build/hero/extract_mannequin.py   # mannequin mesh/weights/skeleton -> build/mannequin.npz
$PY tools/build/hero/body_sdf.py            # smooth body volume (SDF)
$PY tools/build/hero/geometry_cache.py      # marching-cubes meshes for every part + coat cloth grid
$PY tools/build/hero/build_hero.py          # decimate, skin, bake textures, export GLB
$PY tools/build/arms/build_arms.py          # lances + shields GLB
```

* Shapes are signed distance fields (`tools/build/hero/parts.py`): the
  mannequin volume inflated into tee / jeans / coat, a sculpted head placed on
  the face photo's landmarks, slicked-back hair with a crisp undercut line,
  bun, ears, hands from the finger bones, sneakers.
* Textures are projected from the sheet pieces (garment flat-lays unwrapped
  around elliptic cross-sections, face photo frontally, hands/forearms/shoes
  planar or cylindrical) and baked into per-material atlases
  (`tools/build/hero/paint.py`, `bake.py`).
* Skin weights are transferred from the original mannequin and smoothed.
